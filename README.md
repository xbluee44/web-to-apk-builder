# Web to APK Builder

Auto-build APK dari URL website via GitHub Actions.

## Cara Pakai

### Manual (via GitHub UI)
1. Buka tab **Actions**
2. Pilih **Build APK** → **Run workflow**
3. Isi URL, App Name, Package Name
4. Klik **Run workflow**
5. Tunggu selesai → download artifact
